# Templates para Abertura de Issues - Bens Seguros

Templates simples para o PO usar ao criar cartoes no Jira.

---

## Feature / Melhoria

```
**O que precisa ser feito:**
[Descreva o que o sistema deveria fazer]

**Por que e importante:**
[Qual problema isso resolve ou qual beneficio traz]

**Como funciona hoje:**
[Se ja existe algo parecido, descreva. Se nao, escreva "Nao existe"]

**Como deveria funcionar:**
[Descreva o comportamento esperado, passo a passo]

**Observacoes:**
[Qualquer detalhe extra, prints, referencias]
```

---

## Bug

```
**O que aconteceu:**
[Descreva o erro]

**O que deveria acontecer:**
[Comportamento correto esperado]

**Como reproduzir:**
1. Acesse [tela/pagina]
2. Clique em [botao/acao]
3. Observe [o erro]

**Print/Evidencia:**
[Cole um print ou descreva o que aparece na tela]
```
