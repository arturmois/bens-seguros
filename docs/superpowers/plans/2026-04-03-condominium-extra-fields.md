# Condominium Extra Fields Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add structural and safety fields (blocks, elevators, employees, security/fire equipment) to the condominium insured-object form.

**Architecture:** Extend the existing `condominiumDetailsSchema` Zod schema on the backend, mirror the fields in the frontend `CondominiumDetails` interface and `CondominiumFields` form component, and regenerate the Orval API client. No Prisma migration needed — data is stored as JSON.

**Tech Stack:** Zod, TypeScript, React 19, React Hook Form, Orval

**Spec:** `docs/superpowers/specs/2026-04-03-condominium-extra-fields-design.md`

const condominiumDetailsSchema = z.object({

  blockCount: z.number().int().optional(),

function CondominiumEquipmentFields({ register, control }: FieldHelperProps) {
