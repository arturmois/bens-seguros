📌 Regras propostas

  • Criação (CAPTURE): só cliente + ramo + tipo. Zero campos do objeto.
  • Cotação (QUOTE): corretor preenche os campos acima para solicitar cotação à seguradora.
  • Armazenamento: campo details Json? no model Proposal (flexível, sem migration por ramo).
  • Campos com * são obrigatórios para avançar de QUOTE → PROTOCOL.
