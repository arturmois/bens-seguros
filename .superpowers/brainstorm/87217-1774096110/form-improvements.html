3. Selects bugados → Trocar para Select nativo estilizado

❌ Problema atual

@base-ui Select dentro de Sheet/Dialog:

  • Popup abre e fecha instantaneamente
  • Conflito de portal/z-index com o overlay
  • Impossível selecionar opção
✅ Solução

Usar <select> nativo com estilo Tailwind dentro de Sheets/Dialogs:

100% confiável em qualquer contexto modal

Manter shadcn Select nos toolbars (fora de modais) onde funciona. Usar nativo dentro de Sheet/Dialog.
