Comportamentos

Slug Auto-gerado

  • Gerado em tempo real a partir do nome
  • Usa slugify(): lowercase, remove acentos, substitui espaços por hífens
  • Editável pelo usuário
  • Validação de unicidade via debounce (500ms)
  • Exibe ✓ ou ✗ ao lado do campo

Validações

  • Nome: mín 2 caracteres, obrigatório
  • Slug: mín 3 caracteres, regex [a-z0-9-]
  • Slug único (check async no backend)
  • Erros inline abaixo do campo

Ação do Botão

  1. authClient.organization.create()
  2. authClient.organization.setActive()
  3. Member criado com role OWNER
  4. Redirect para / (dashboard)

Proteções

  • Rota protegida (requer sessão)
  • Se já tem org → redirect para /
  • Loading state no botão
  • Toast de erro em caso de falha
