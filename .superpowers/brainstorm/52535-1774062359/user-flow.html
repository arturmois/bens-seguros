Login → Verificação → Dashboard ou Seleção

Email + Senha
→
Decisão

→

NÃO: /select-org

Regras de Redirecionamento (proxy.ts)

  • Sem sessão → /login (já implementado)
  • Com sessão, sem org ativa, sem orgs → /onboarding
  • Com sessão, sem org ativa, com orgs → /select-org
  • Com sessão, org ativa válida → acesso normal
  • /onboarding e /select-org → rotas protegidas (requer sessão)
